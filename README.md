Homework from Jupyter Notebooks

## DataScienceEcosystem.ipynb

`DataScienceEcosystem.ipynb` is a short summary of the data science tools and ecosystem, written mostly as Markdown notes. It is a Python notebook, but its code cells only demonstrate simple arithmetic — nothing is imported, loaded, plotted, or trained.

### Objectives

The notebook's stated objectives are:

- List popular languages for Data Science
- Commonly used libraries
- Data Science Tools
- Evaluating Expressions

### Contents

- **Popular languages** — Python, R, SQL, C++
- **Commonly used libraries** — NumPy, PyTorch, pandas, scikit-learn
- **Data Science tools** — RStudio, Apache Spark, TensorFlow, listed in a small table
- **Arithmetic examples** — two Python code cells: `(3*4)+5`, which evaluates to `17`, and one converting 200 minutes to hours, which prints `3.3333333333333335`
- **Author** — an author cell naming Baja Poawui
